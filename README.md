| 누가 | 무엇을 | 준비물 |

## 2. 배포 담당이 처음 한 번만 (약 15분)

### 2-1. Firebase 프로젝트 만들기

1. <https://console.firebase.google.com> 에 구글 계정으로 들어가요.
2. **프로젝트 만들기** → 이름 예: `relay-story-sinseo` → Google 애널리틱스는 **끄기** → 만들기.
3. 요금제는 기본값 **Spark(무료)** 그대로 두세요. 카드 등록이 필요 없어요.

### 2-2. 익명 로그인 켜기

1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**.
2. **로그인 방법(Sign-in method)** 탭 → **익명(Anonymous)** → 사용 설정 → 저장.

학생은 이메일이나 이름 없이 '익명 계정'으로 들어와요. 같은 디벗에서 새로고침해도 같은 학생으로 이어져요.

### 2-3. Realtime Database 만들고 보안 규칙 넣기

1. **빌드 → Realtime Database → 데이터베이스 만들기**.
2. 위치: **싱가포르 (asia-southeast1)** (한국에서 가장 가까워요).
3. **잠금 모드로 시작** → 사용 설정.
4. **규칙** 탭을 열고, 들어 있는 내용을 모두 지운 뒤 `database.rules.json` 파일 내용을 그대로 붙여 넣고 **게시**.

이 규칙 덕분에 학생은 자기 화면만 읽을 수 있고, 진행 상태와 영상은 교사 화면만 바꿀 수 있어요. (우리 모둠이 에뮬레이터로 11가지 경우를 시험했어요.)

### 2-4. 웹 앱 등록하고 `js/config.js`에 붙여 넣기

1. 왼쪽 위 ⚙️ **프로젝트 설정 → 일반 → 내 앱 → 웹(`</>`)** 아이콘.
2. 앱 닉네임 예: `relay-story` → Firebase 호스팅은 체크하지 않음 → 앱 등록.
3. 화면에 나오는 `firebaseConfig = { ... }` 의 중괄호 안 내용을 복사해서 `js/config.js` 의 `firebase: null` 자리에 넣어요.

```js
window.RSL_CONFIG = {
  credit: "중앙대학교 영어교육과 · 이진화 교수 | 영어교과교육과정 프로젝트로 개발된 프로그램입니다.",
  firebase: {
    apiKey: "AIza...",
    authDomain: "relay-story-sinseo.firebaseapp.com",
    databaseURL: "https://relay-story-sinseo-default-rtdb.asia-southeast1.firebasedatabase.app",
    projectId: "relay-story-sinseo",
    appId: "1:1234567890:web:abcdef",
  },
};
```

- `databaseURL` 줄이 없으면 Realtime Database 화면 맨 위에 보이는 주소(`https://...firebasedatabase.app`)를 직접 적어 주세요.
- `apiKey`는 비밀번호가 아니에요. 웹 앱에는 원래 공개되는 값이고, 데이터는 2-3의 보안 규칙이 지켜요.

### 2-5. Netlify에 올리기 (끌어다 놓기)

1. <https://app.netlify.com/drop> 에 로그인한 상태로 들어가요.
2. 이 폴더(`relay-story-live`) 전체를 창에 끌어다 놓으면 1분 안에 주소가 생겨요 (예: `https://relay-story-sinseo.netlify.app`).
3. **Site configuration → Change site name**에서 기억하기 쉬운 이름으로 바꿀 수 있어요.
4. 내용을 고친 뒤 다시 올릴 때는 사이트의 **Deploys** 탭에 폴더를 다시 끌어다 놓아요.

Netlify 대신 GitHub Pages, Cloudflare Pages, Firebase Hosting 어디에 올려도 똑같이 동작해요 (그냥 정적 파일이에요).

### 2-6. 시험해 보기 (5분)

1. 컴퓨터에서 `https://(사이트 주소)/host.html` → 오른쪽 위에 **수업 모드**와 5자리 코드가 보이면 성공.
2. 휴대폰 두 대로 QR을 찍어 입장 → 교사 화면 '참여 2명'.
3. 오류 안내가 나오면:
   - "익명 로그인이 꺼져 있어요" → 2-2 다시 확인
   - "보안 규칙이 아직 안 들어갔어요" → 2-3의 4번 다시 확인
   - 수업 모드 대신 시연 모드가 보이면 → `js/config.js`의 `firebase:` 칸이 비어 있어요

교사에게는 **사이트 주소 하나**와 아래 3장만 전달하면 돼요.

## 3. 교사용 수업 안내 (45분, 영어 설명 필요 없음)

### 수업 전 (5분, 처음 한 번)

- 전자칠판(또는 교사 컴퓨터)에서 **Microsoft Edge**로 사이트를 여세요. Edge에는 자연스러운 영어 음성이 들어 있어요. 크롬도 됩니다.
- 디벗 한 대로 미리 입장해 보고, 전자칠판 소리가 나오는지 확인하세요.
- 같은 주소의 `demo.html`(시연 모드)에서 흐름을 미리 한 번 둘러보면 좋아요.

### 수업 흐름

| 단계 | 시간 | 교사가 누르는 것 | 학생이 하는 것 |
|---|---|---|---|
| 0 입장 | 3분 | 교사 화면 열기 (주제는 자동 추천됨, 바꾸려면 **🎲 다른 주제 추천** 또는 **주제 모두 보기**) → 모둠 수 정하기 | QR 찍기 → 별명, 모둠 고르기 → ✍️ 작가 서약 체크 → 입장 |
| 1 오늘의 주제 | 2분 | 화면의 **안내 멘트**를 그대로 읽기 (주제가 한국어·영어로 함께 나와요) | 주제와 등장인물 확인 |
| 2 단어 | 12분 | **▶ 자동으로 넘기기** (컴퓨터가 단어·예문을 읽고 넘김) → 🎣 단어 낚시 / 🏃 단어 달리기 중 하나 고르기 → 시간(5·7·10분) 고르고 **시작** → 실시간 모둠 순위·희귀 물고기·신서중 도착 알림 보기 → 시간이 끝나면 자동으로 많이 틀린 단어 TOP 3 복습 | 단어 카드(이모지·강세·뜻·기억 팁·예문 뜻) → 🎣 **단어 낚시**: 문제(뜻의 문, 강세 달걀, 듣고 고르기, 철자 퍼즐, 빈칸)를 맞히면 미끼, 찌가 쏙 들어가면 눌러 낚기, 물고기마다 오늘의 단어가 하나씩 붙어 나옴, 코인으로 낚싯대·낚시터(신서중 연못 → 산호 바다 → 중앙대 청룡연못) 업그레이드 / 🏃 **단어 달리기**: 푸앙이가 중앙대에서 신서중 정문까지 달려요. 위·아래로 줄을 바꿔 정답 문을 지나고, 점프로 장애물을 넘고, 글자 타일을 순서대로 모으면 피버 타임 → 내 점수와 틀린 단어 복습. 모둠 정답률에 따라 영상 보너스: 50% 배경음악, 70% 캐릭터별 목소리, 85% 보너스 장면 |
| 3 릴레이 소설 | 14분 | **3 릴레이 소설로 →** (누르면 모둠마다 첫 번째 학생 차례가 시작됨) → 모둠 카드에서 지금 쓰는 학생과 **쓰는 글을 실시간으로** 보기 → 필요하면 **모두 +1분**, **모두 다음 차례로**, 모둠별 **차례 넘기기** | 모둠이 이야기 하나를 **한 명씩 차례로** 이어 쓰기. 내 차례면 쓰고 → 제출하면 바로 다음 친구 차례. 내 차례가 아니면 친구가 쓰는 글을 내 디벗에서 실시간으로 보기(다음 차례인 학생에게는 알림). **🧩 쉬운 모드**를 고르면 문장 틀을 고르고 칸마다 단어만 골라 넣어요(우리말 자막 줄도 같이 들어감). **✏️ 도전 모드**는 자유롭게 써요. **💡 힌트**(미션 단어·예문, 표현, 우리말로 단어 찾기, 화면 묘사 틀)를 누르면 바로 넣을 수 있고, **영어 도우미**가 대문자·마침표·a/an·동사 형태·철자를 알려 줘요 (안 고쳐도 제출됨). 장면마다 **우리말 자막**을 쓰면 영상에 같이 나와요 |
| 4 AI 영상 | 4분 | **🎬 모든 이야기를 영상으로** → 썸네일·전체 글 미리보기 (모둠마다 한 편) | 우리 모둠 이야기 다시 읽기 |
| 5 함께 보기 | 10분 | ▶ 재생 (전체 화면, **우리말 자막**·**빠르게** 켜고 끄기) → 다음 모둠 → 시상 | 반응 이모지, 베스트 스토리 투표 |

- 권장 설정(29명): **모둠 6개(4~5명) · 쓰기 차례 자동 · 한 차례 3분**. '자동'은 모둠에서 가장 많은 인원만큼(2~6화) 써서 한 명이 한 화씩 맡아요.
- 릴레이 소설은 **턴제**예요. 모둠마다 이야기가 하나이고, 한 명이 쓰는 동안 나머지 친구들은 그 글이 써지는 모습을 자기 디벗에서 바로 봐요. 교사 화면에도 모둠별로 지금 쓰는 글이 보여요.
- 모둠마다 자기 속도로 가요. 다 쓰고 제출하면 바로 다음 친구 차례가 되고, 시간이 끝나면 쓰던 글이 자동으로 저장된 뒤 넘어가요.
- 실시간으로 보이는 글에서 금지어와 실명은 `***`로 가려져요. 제출할 때는 고쳐야 통과돼요.
- **모두 +1분**, **모두 다음 차례로**로 속도를 조절하고, 자리에 없는 학생은 그 모둠 카드의 **차례 넘기기**로 건너뛸 수 있어요 (같은 화를 다음 친구가 써요).
- 늦게 온 학생은 들어오면 모둠 차례표 맨 뒤에 붙어요.
- 시상 화면의 **📋 오늘의 수업 기록**에 참여 인원, 단어 게임 정답률, 쓴 문장 수, 미션 단어 사용 수가 나와요. 학급 스티커를 줄 때 쓰세요.
- 주제는 36개가 단어·뜻·예문·발음까지 들어 있어요. 교사 화면이 그 컴퓨터에서 아직 안 한 주제를 고르고, 학생 설문에서 인기가 많았던 대중문화·여행 주제와 지금 계절에 맞는 주제를 먼저 추천해요.
- 학생이 우리말 자막을 안 쓴 줄은, 교사 컴퓨터의 크롬에 내장 번역 기능이 있으면 영상을 만들 때 자동으로 채워요 (인터넷으로 글을 보내지 않음). 없으면 영어 자막만 나와요.
- 영상 파일로 남기고 싶으면 재생하면서 화면 녹화를 하세요 (Windows: `Win + Alt + R`).

### 문제가 생기면

- **학생 화면이 멈춤** → 새로고침. 같은 디벗이면 같은 학생으로 이어져요.
- **교사 화면을 실수로 닫음** → 같은 컴퓨터에서 다시 열면 같은 수업 코드로 이어져요.
- **다음 수업(다른 반)** → 시상 화면의 🗑 **오늘 수업 기록 지우기**, 또는 1단계의 **새 수업 (처음부터)**.
- **직접 주제를 만들고 싶음 (선택)** → 1단계 오른쪽의 **직접 만들기**. 단어는 중학교 기본 어휘 목록에 있는지 자동으로 확인해 줘요. 만든 주제는 그 컴퓨터에 저장돼요.

## 4. 안전 장치 (교육적이지 않은 내용 막기)

1. **오늘의 주제는 미리 만든 36개 중에서 골라요.** 등장인물과 장면도 주제에 맞게 정해져 있어요.
2. **작가 서약** 체크 없이는 입장할 수 없어요.
3. **제출할 때 자동 검사**: 금지어(욕설, 폭력, 선정 표현, 한국어 비속어 포함)와 반 친구 실명이 들어가면 제출이 막히고 고칠 곳을 알려 줘요. 1단계 🛡 **실명·금지어 설정**에 우리 반 학생 이름과 추가 금지어를 넣을 수 있어요 (이 컴퓨터에만 저장, 서버로 보내지 않음).
4. **교사 미리보기**: 4단계에서 모든 이야기의 전체 글을 영상 재생 전에 볼 수 있어요.
5. **우리 반만 공유**: 영상관은 수업 코드를 아는 사람만 열 수 있고, 🗑 버튼으로 언제든 지울 수 있어요.

개인정보: 학생 이름, 이메일, 사진을 받지 않아요. 별명과 익명 계정만 써요. 수업 데이터는 Firebase(싱가포르 서버)에 저장되고, 🗑 버튼을 누르면 모두 지워져요.
